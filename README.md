# 8bit_PONG
Very basic PONG like mini game with PIC16F913 MCU and SSD1351 Adafruit Display.

##### You need to buy PICkit from Microchip for flashing the microcontroller, also to download MPLAB_ide and MPLAB_ipe from [here](https://www.microchip.com/en-us/tools-resources/develop/mplab-x-ide) for programming
